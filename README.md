## 🧠 Featured Projects

### 🔌 VISIO-MCP

**Microsoft Visio × Model Context Protocol**

A Windows MCP server that allows MCP-compatible AI clients to control Microsoft Visio through COM automation.

**Capabilities include:**

* Create Visio diagrams
* Read existing diagrams
* Edit shapes and diagrams
* Export diagrams
* Structured MCP tools
* Windows COM automation
* AI-agent integration

🔗 **Repository:**
https://github.com/SONA-LK/VISIO-MCP

---

### 📊 EXCEL-MCP

**Microsoft Excel × AI Agents**

An MCP server designed to give AI assistants programmatic control over Microsoft Excel workbooks.

The project focuses on operations such as:

* Workbook manipulation
* Worksheets
* Cells
* Formulas
* Formatting
* Tables
* Data manipulation
* Excel automation

🔗 **Repository:**
https://github.com/SONA-LK/EXCEL-MCP

### ⚡ Go Reverse Proxy & Load Balancer

A production-oriented HTTP/HTTPS reverse proxy and load balancer written in **Go**.

Features include:

* Round-robin load balancing
* Least-connections balancing
* Weighted round-robin
* Active health checks
* Automatic failover
* Automatic recovery
* Safe request retries
* Connection pooling
* Configurable timeouts
* Token-bucket rate limiting
* Structured JSON logging
* Request IDs
* Prometheus metrics
* Admin REST API
* Web dashboard
* Graceful shutdown
* TLS support

🔗 **Repository:**
https://github.com/SONA-LK/Reverse-Proxy

---

### 🌐 Antigravity Browser Companion

A browser automation bridge combining:

**Chrome MV3 Extension + Node.js Native Messaging + MCP**

It connects AI tooling with browser capabilities such as:

* Browser DOM interaction
* DevTools
* Browser automation
* Native messaging
* MCP-based tool access

🔗 **Repository:**
https://github.com/SONA-LK/antigravity-browser-companion

---

### 📹 Web-to-Web Video Calling

A WebRTC-based browser-to-browser video calling project designed around **peer-to-peer communication** with a lightweight backend.

The architecture focuses on minimizing infrastructure and avoiding expensive third-party communication platforms.

🔗 **Repository:**
https://github.com/SONA-LK/web-to-web-video-calling
